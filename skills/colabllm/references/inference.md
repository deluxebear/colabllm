# Inference runtimes

- [Qwen Flash](qwen-flash.md): authenticated OpenAI-compatible text/vision inference.
- [DeepSeek Coder](deepseek-coder.md): `DeepSeek-V4.1-Flash-1017` uncensored GSQ-RCO Coder + host-RAM/SSD Engram + vision, thinking on by default with per-request client `enable_thinking` control, and hardware-adaptive max context up to 1M.
- [Ollama](ollama.md): auto-pulled Ollama/HF GGUF models, selectable `ollama`/`openai`/`anthropic` compatible APIs, and `OLLAMA_*` server tuning.
- [Unsloth Studio](unsloth-studio.md): UI training, inference and export.

Read the selected runtime guide; CLI and authentication differ between these services.
